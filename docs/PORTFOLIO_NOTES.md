# Ficha de portafolio

## Descripción corta

Asistente web bilingüe para una comunidad de VRChat que convierte datos de pesca y equipamiento en recomendaciones, rankings y comparaciones interactivas.

## Mi aporte

- Identificación del problema y definición de la solución.
- Modelado de peces, equipamiento, zonas, condiciones, misiones y NPC.
- Implementación de reglas de puntuación y recomendación en JavaScript.
- Diseño de buscadores, filtros, rankings y comparadores.
- Diseño visual responsive y soporte español-inglés.

## Competencias demostradas

- Análisis y modelado de requisitos
- Lógica de negocio en JavaScript
- Manejo del DOM y eventos
- Diseño responsive con CSS
- Organización de datos y filtros
- UX orientada a decisiones
- Control de versiones con Git

## Evidencias recomendadas

- Vista principal del asesor con una configuración seleccionada.
- Buscador mostrando filtros y resultados.
- Ranking o comparador con al menos dos configuraciones.
- Vista móvil para demostrar adaptación responsive.
